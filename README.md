# Strata-Site

Strata(Mac App Store판) 공개 페이지입니다. GitHub Pages가 저장소 루트를 그대로 내보냅니다.
https://bbdyno.github.io/Strata-Site/

- 영어: `index.html`, `privacy.html`, `support.html`, `terms.html`
- 한국어: `ko/` 아래 같은 이름
- 스타일: `assets/site.css`

빌드 단계는 없습니다. 머리글·바닥글은 페이지마다 들어 있으니 바꿀 때는 8쪽 모두 고칩니다.
App Store Connect에 건 개인정보·지원 주소가 있으니 파일 이름은 옮기지 않습니다.
